# Bienvenue !

Bienvenue sur l’espace dédié à la documentation de la page d’administration du site **coiffeuse-chartres.fr**, site de présentation des activités Sandrine Reigaza.

Cette documentation a été créée pour vous aider à **gérer efficacement le contenu du site** : contenu et changement de tarif.

## A quoi sert cette documentation

Cette documentation vous guidera pas à pas pour :

- Modifier les textes et images des pages du site,
- Modifier le bon d'achat,
- ajouter, modifier ou supprimer des tarifs.

## Un mot important...
> “Un grand pouvoir implique de grandes responsabilités.” – Oncle Ben

L’administration du site donne accès à des fonctionnalités sensibles. Chaque modification impacte directement les informations présentées au public.

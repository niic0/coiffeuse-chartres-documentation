# Modifier les avis google
Cette page explique comment utiliser la page [Modifier les Avis Google](https://coiffeuse-chartres.vercel.app/admin/index.html#/collections/edit/googleAvis/googleAvis) du site d'administration.

Vous pouvez directement modifier le texte puis ensuite cliquer sur "Save" pour mettre en ligne les modifications.
